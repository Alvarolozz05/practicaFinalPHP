# Tablón de anuncios

Aplicación web desarrollada en PHP que permite gestionar publicaciones y comentarios.

## Tecnologías

- PHP 8.3
- MySQL 8.4
- Docker
- HTML y CSS

## Instalación

1. Clonar el repositorio.
2. Ejecutar el proyecto con Docker:

```bash
docker compose up -d
```

3. Importar la base de datos `tablon_anuncios.sql`.

## Acceso

- **Aplicación:** http://localhost:8080
- **phpMyAdmin:** http://localhost:8081
